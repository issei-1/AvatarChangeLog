# Avatar Change Log v0.1.1

最新版 v0.1.1 をGitHubで公開しています。
VRChatアバターの改変を自動記録するUnity Editor拡張です。

## 導入と使い方

対象はUnity 2022.3.22f1です。VRChat SDKへの直接依存や追加パッケージはありません。
1. Assets > Import Package > Custom PackageからAvatarChangeLog-0.1.1.unitypackageを導入します。
2. Tools > Avatar Change Logを開きます。
3. 保存済みシーン内のアバタールートをアバター欄にドラッグします。
4. 通常どおり改変すると変更ログが追加されます。
5. アバター欄の下に対象名と「記録中／一時停止中」を表示します。欄の右側の「一時停止」「記録を再開」で切り替えます。Unity処理中や開始前は待機状態、開始に失敗した場合はエラー状態を表示します。

## 実装機能

- 改変を自動記録：オブジェクト・Transform・シェイプキー・マテリアル・コンポーネントの変更に対応。
- マテリアル変更を見やすく表示：数値・色・テクスチャ・UVの変更を記録。lilToonの項目名にも対応。
- 関連する変更を集約：衣装の追加・削除、同一マテリアルの変更、SDKのAuto Fixをまとめ、内訳は詳細で確認。
- 変更前後を比較：数値や色見本で違いを表示し、細かな設定や参照先は詳細に整理。
- 検索・分類・日付別表示：キーワード検索、分類フィルター、日付ごとの折りたたみに対応。
- 記録の一時停止・再開：指定中の1体を記録し、停止状態はアバターごとに保存。停止中の変更は記録しません。
- ウィンドウを閉じても記録を継続。
- TXT出力：検索結果を一覧と詳細に分けて書き出せます。

## 記録と保存

- 記録方法：初回に比較の基準を保存し、以後は変更を自動保存。連続操作はまとめて記録します。
- Unity処理中は待機：再生・コンパイル・インポート中などは記録を止め、再開時に差分をまとめます。
- 手動停止中の変更は除外：再開時の状態を基準に、その後の変更だけを記録します。
- 保存上限：アバターごとに最新100状態を保存。初回・再開時の基準も含み、画面のログ行数とは異なります。
- 保存先：プロジェクト内の UserSettings/AvatarChangeLog。保存成功後に古い状態を整理し、破損・不明なファイルは自動削除しません。
- 保存エラーの通知：保存・整理に失敗すると画面とConsoleに表示。整理は再試行します。
- AutoFixは1回分を集約：変更があった場合に処理後の状態を1件保存し、直前の手作業とは分けて記録します。
- 不要な内部情報を除外：SDKが自動生成する animationHashSet は記録・表示の対象外です。
- 更新方法：v0.1.0から上書き導入でき、履歴と設定を引き継ぎます。更新時は保存フォルダを削除しないでください。開発初期の旧形式には非対応です。

## 制限

- 履歴の確認専用：復元・Undo代替・ビルドエラー診断には対応していません。バックアップの代わりにはなりません。
- 記録対象に制限あり：未保存の一般アセット、一部のデータ型や参照、プロジェクト全体の設定などは追跡できない場合があります。
- AutoFixの集約条件：SDKで選択中のアバターと記録対象が一致し、SDKパネルのボタンをマウス・キーボードで実行した場合に対応。タッチ操作は非対応で、一時停止中は記録しません。
- SDKによる制限：SDK 3.10.4／3.10.5の実装をソースで確認済みです。SDKの仕様変更、スクリプト経由の修正、遅れて発生する処理は集約できない場合があり、取得できた変更は通常のログとして記録します。

## 検証

本体と統合テストをUnity 2022.3.22f1の参照で別アセンブリとしてコンパイルし、Unity非依存の235テストグループを実行しました。
差分・集約・検索・TXT出力・保存上限などを検証しています。AutoFixの複数分類集約、詳細の欠落防止、別対象の場所の分離、次の手作業を分離する表示処理も確認しています。
項目キーは区切り文字・日本語・絵文字・空文字など4,096通りで旧処理と一致することを確認しました。
記録処理の中間保存抑制・JSON再読込・直前の手作業保存・連続実行・一時停止を確認するUnity統合テストを追加しています。
Unity Editorの直近の起動はライセンスクライアント接続失敗で中断したため、実操作および統合テスト実行は未確認です。配布前にRELEASE-CHECKLIST.mdの項目を確認してください。
アバター欄が空の間はログを表示しません。対象シーンを閉じた場合も保存済み履歴は保持し、対象が復帰すると再表示します。
