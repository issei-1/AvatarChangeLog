# Avatar Change Log v0.1.1

現行版 v0.1.1 をGitHubで公開しています。タイトルロゴの変更を含みます。

VRChatアバターの改変を自動記録するUnity Editor拡張です。

## ダウンロード

- [最新版のunitypackageをダウンロード](https://github.com/issei-1/AvatarChangeLog/releases/latest/download/AvatarChangeLog-0.1.1.unitypackage)
- [説明書付きZIPをダウンロード](https://github.com/issei-1/AvatarChangeLog/releases/latest/download/AvatarChangeLog-0.1.1.zip)
- [リリース一覧](https://github.com/issei-1/AvatarChangeLog/releases)

通常の導入にはunitypackageを使用してください。ソースコードはこのリポジトリのAssets/AvatarChangeLogにあります。

## 導入と使い方

対象はUnity 2022.3.22f1です。VRChat SDKへの直接依存や追加パッケージはありません。
1. Assets > Import Package > Custom PackageからAvatarChangeLog-0.1.1.unitypackageを導入します。
2. Tools > Avatar Change Logを開きます。
3. 保存済みシーン内のアバタールートをアバター欄にドラッグします。
4. 通常どおり改変すると変更ログが追加されます。
5. アバター欄の下に対象名と「記録中／一時停止中」を表示します。欄の右側の「一時停止」「記録を再開」で切り替えます。Unity処理中や開始前は待機状態、開始に失敗した場合はエラー状態を表示します。

## 実装機能

- オブジェクト・Transform・シェイプキー・マテリアル・コンポーネント設定の自動記録。
- マテリアルの未保存の数値・色・テクスチャ・UV変更を取得。lilToonは取得可能なInspector表示名を使用。
- 衣装等の追加・削除を親1件に集約し、子オブジェクトと参照アセットは詳細で表示。
- VRChat SDKの「Auto Fix」ボタン1回の実行による変更を、一覧ではアバター名・Auto Fix・変更項目数の1行に集約。詳細に各項目の分類・場所・変更前後を残します。分類フィルターは内訳に該当する変更がある場合に表示し、検索とTXT出力も内訳を含みます。
- Auto Fixの詳細は各変更自身の場所を表示します。別のマテリアルやオブジェクトに同じ項目・同じ変更前後値があっても参照先は混ぜません。通常の共有マテリアルの変更は従来どおり共有先をまとめて表示します。
- 同じ記録内の同一マテリアルの変更を1件に集約。一覧は代表的な変更1項目と「ほか○項目」に絞り、残りの変更・内部設定・保存情報・共有先は詳細で確認します。色は前後の色見本、数値は「1.00 → 0.70」のように表示。別の記録・別のマテリアルは集約しません。
- 色見本にマウスを重ねるとRGBA値を確認できます。透明色は市松模様の背景、HDR値は注記付きで表示します。色の種別情報がない既存履歴は数値で表示。TXTでは色見本の代わりにRGBA値を出力し、省略した項目も詳細に残します。
- すべてのログで項目名を太字にし、その下に「変更前」「変更後」を並べて表示。変更後の値を強調します。位置・スケールはX／Y／Z、有効状態は有効／無効、追加削除はなし／ありで表記。色の透明度は「不透明度 ○%」と表示します。
- 対象欄は名前と分類を表示し、階層パスや子の内訳は詳細にまとめます。回転の内部数値、長文、内部設定、アセットの識別値は一覧では変更の要点を示し、元の値は詳細で確認できます。同名の参照先への変更も更新があったことを表示します。
- 分類フィルターと文字検索。空白区切りの複数語はAND検索、全角英数字も正規化。
- ログは時刻・操作、対象・分類、変更内容の一覧表で表示。画面・TXTの時刻は分まで（例：20:33）表示します。40件／ページ、詳細20件／ページ。TXTも全分類を共通の項目名・変更前後の形式に揃え、検索結果の全ページをID付き一覧と詳細に分けて出力します。詳細へ移した値・パス・項目名も検索できます。
- 同時に記録する対象は指定中の1体です。ウィンドウを閉じても記録を継続します。一時停止状態はアバターのIDごとに保存し、別アバターへの切り替え・Unity再起動後も維持。同名の別アバターは別々に扱います。停止していない対象は再起動後のシーン読み込み時に記録を再開します。
- 一時停止すると対象の変更監視・定期取得・履歴保存を止めます。停止直前の未確定な変更は保存し、停止中の操作はログに残しません。「記録を再開」を押した時点の状態を比較基準として保存し、以後の変更だけを記録します。保存に失敗した場合は状態を切り替えず、エラーを表示します。
- 日付の見出しをクリックすると、その日のログを展開・折りたたみできます。初期状態は展開。40件ごとのページをまたぐ同じ日付にも折りたたみ状態を適用します。自動記録・再読込では状態を維持し、検索条件変更・アバター切り替えで展開に戻ります。「最新へ」は最新ログの日付を展開。折りたたみは画面表示だけに作用し、検索件数・TXT出力・保存履歴には影響しません。状態はウィンドウの利用中のみ保持します。

## 記録と保存

初回は比較の基準となる状態を保存します。以後、状態が変わった場合に保存します。
シェイプキーとマテリアル値は約0.2秒ごとに確認し、最後の変更から約0.65秒後に保存します。連続操作は最長約5秒で区切ります。全体確認は原則3秒間隔で、負荷に応じて間隔が延びます。
再生・コンパイル・インポート中やUnity終了中は記録しません。再開時には差分をまとめて記録します。
上記はUnityの処理による待機の動作です。ユーザー操作による一時停止では、停止中の差分は表示・検索・TXT出力の対象にしません。再開時の比較基準も保存上限100状態に含まれます。停止中も対象の存在と状態の軽い確認は続けますが、アバター配下の変更監視は行いません。

保存先はプロジェクト内のUserSettings/AvatarChangeLogです。各アバターの保存状態は最新100件固定です。1回の保存に複数の変更を含むため、画面上のログ行数が100行とは限りません。初回の基準を含む最大100状態間の差分を表示します。正常保存後に古い状態を整理します。破損・不明なファイルは自動削除しません。

保存や整理に失敗した場合は画面とConsoleへ通知します。整理失敗は再試行し、成功時に通知を解除します。

Auto Fix中は途中の状態を保存せず、処理後の状態を1件だけ保存します。実行直前に未記録の手作業がある場合は先に別件として保存し、Auto Fixと混ぜません。変化がなかった実行では保存件数を増やしません。ボタンを複数回押した場合は実行ごとに記録します。通常の同時変更や導入前のログをAuto Fixと推測して集約することはありません。上限100件は引き続き表示行数ではなく、アバターごとの保存状態数です。

SDKが検証時に再生成するVRCAvatarDescriptorのanimationHashSet（アニメーションの内部デバッグ情報）は記録対象外です。この情報だけの更新では保存しません。既存履歴も読み込み時に同項目を除外するため、表示・検索・TXTに不要な設定変更が並ばなくなります。元の保存ファイルは書き換えず、過去に消費した保存件数は変わりません。アニメーションレイヤーなど実際の設定変更や、別コンポーネントの同名項目は引き続き記録します。

v0.1.0からはunitypackageを上書き導入できます。記録形式2を維持しているため、UserSettings/AvatarChangeLogの保存済み履歴と設定はそのまま使用します。更新時にこの保存フォルダを削除しないでください。開発初期の旧記録形式からの移行には対応していません。

## 制限

履歴の復元・Undo代替・ビルドエラー診断はありません。記録は対象のシリアライズ値と参照アセットの識別値に基づきます。未保存の一般アセット、取得非対応の型、永続IDのない参照などは完全には追跡できません。記録はバックアップの代用ではありません。

Auto Fixの集約は、SDKの選択アバターが記録中の対象と一致し、SDKパネルの「Auto Fix」ボタンをマウスまたはキーボードで実行した場合が対象です。タッチ操作の集約には対応していません。一時停止中の変更は記録しません。SDK 3.10.4／3.10.5のボタン実装・公開APIをソースで確認しています。SDKの画面構成が変更された場合や、スクリプトから直接呼び出した修正、遅延・非同期の追加処理は集約できない場合があります。検出できない場合は通常の変更記録になります。プロジェクト全体の設定など、元々の取得対象外の変更は記録しません。

## 検証

本体と統合テストをUnity 2022.3.22f1の参照で別アセンブリとしてコンパイルし、Unity非依存の235テストグループを実行しました。差分・集約・検索・TXT出力・保存上限などを検証しています。Auto Fixの複数分類集約、詳細の欠落防止、別対象の場所の分離、次の手作業を分離する表示処理も確認しています。項目キーは区切り文字・日本語・絵文字・空文字など4,096通りで旧処理と一致することを確認しました。記録処理の中間保存抑制・JSON再読込・直前の手作業保存・連続実行・一時停止を確認するUnity統合テストを追加しています。Unity Editorの直近の起動はライセンスクライアント接続失敗で中断したため、実操作および統合テスト実行は未確認です。配布前にRELEASE-CHECKLIST.mdの項目を確認してください。

アバター欄が空の間はログを表示しません。対象シーンを閉じた場合も保存済み履歴は保持し、対象が復帰すると再表示します。
